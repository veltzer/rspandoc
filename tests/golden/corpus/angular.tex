\subsection{Description}\label{description}

This course offers a thorough exploration of the Angular framework for
building scalable, enterprise-grade web applications. Starting with
Angular architecture and a \texttt{TypeScript} refresher, the course
covers components, templates, data binding, directives, services,
dependency injection, routing, forms, \texttt{HTTP} communication,
\texttt{RxJS}, state management with NgRx, testing, and deployment.
Students will gain the skills to build, test, and deploy
production-ready Angular applications.

\subsection{Duration}\label{duration}

32 hours / 4 days

\subsection{Intended Audience}\label{intended-audience}

\begin{itemize}
\tightlist
\item
  Frontend developers building enterprise-scale single-page applications
\item
  \texttt{JavaScript} or \texttt{TypeScript} developers adopting the
  Angular framework
\item
  Full-stack developers who need to build robust client-side
  applications
\item
  Development teams migrating from AngularJS to modern Angular
\item
  Software engineers working in organizations that use Angular as their
  primary frontend framework
\end{itemize}

\subsection{Prerequisites}\label{prerequisites}

\begin{itemize}
\tightlist
\item
  Good understanding of \texttt{HTML}, \texttt{CSS}, and
  \texttt{JavaScript} (\texttt{ES6}+ features)
\item
  Basic knowledge of \texttt{TypeScript} (types, interfaces, classes,
  decorators)
\item
  Familiarity with \texttt{npm} and command-line tools
\item
  Understanding of \texttt{HTTP} protocol and \texttt{REST\ API}
  concepts
\item
  Experience with basic web development and browser developer tools
\end{itemize}

\subsection{Required Knowledge}\label{required-knowledge}

\begin{itemize}
\tightlist
\item
  \texttt{HTML} \texttt{CSS} \texttt{JavaScript} Fundamentals (or

\item
  \texttt{TypeScript} Programming (or equivalent experience)
\end{itemize}

\subsection{Objectives}\label{objectives}

\begin{itemize}
\tightlist
\item
  Understand Angular architecture, modules, and the component-based
  model
\item
  Build components with templates, data binding, directives, and pipes
\item
  Implement services and leverage Angular dependency injection system
\item
  Configure client-side routing, navigation, guards, and resolvers
\item
  Build reactive forms and template-driven forms with validation
\item
  Communicate with backend services using HttpClient and interceptors
\item
  Work with \texttt{RxJS} observables for reactive data handling
\item
  Manage application state using NgRx
\item
  Test Angular applications with Jasmine, Karma, and Cypress
\item
  Optimize performance with lazy loading and production builds
\item
  Style applications using \texttt{Angular\ Material}
\end{itemize}
