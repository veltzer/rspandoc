\subsection{Description}\label{description}

Network security is a critical discipline in today's interconnected
world, where organizations face increasingly sophisticated threats
targeting their network infrastructure. This course provides a
comprehensive understanding of network security principles,
technologies, and practices. Students will learn how to protect networks
using firewalls, VPNs, encryption, and intrusion detection systems, as
well as how to analyze traffic, respond to incidents, and design secure
network architectures following modern zero trust principles.

\subsection{Duration}\label{duration}

24 hours / 3 days

\subsection{Intended Audience}\label{intended-audience}

\begin{itemize}
\tightlist
\item
  Security professionals responsible for protecting network
  infrastructure
\item
  System administrators managing firewalls, VPNs, and network devices
\item
  Network engineers transitioning to security-focused roles
\item
  IT professionals preparing for security certifications
\item
  \texttt{DevOps} engineers implementing network security in cloud
  environments
\end{itemize}

\subsection{Prerequisites}\label{prerequisites}

\begin{itemize}
\tightlist
\item
  \texttt{Solid} understanding of \texttt{TCP}/\texttt{IP} networking
  fundamentals
\item
  Familiarity with \texttt{Linux} and \texttt{Windows} command-line
  tools
\item
  Basic understanding of network protocols (\texttt{HTTP}, \texttt{DNS},
  \texttt{DHCP})
\item
  Experience with network device configuration (routers, switches)
\item
  Understanding of basic cryptographic concepts is helpful
\end{itemize}

\subsection{Required Knowledge}\label{required-knowledge}

\begin{itemize}
\tightlist
\item
  \texttt{Linux} Fundamentals (or equivalent experience)
\end{itemize}

\subsection{Objectives}\label{objectives}

\begin{itemize}
\tightlist
\item
  Understand \texttt{TCP}/\texttt{IP} security vulnerabilities and
  attack vectors
\item
  Configure and manage firewalls including next-generation firewalls
\item
  Deploy and manage \texttt{VPN} technologies (\texttt{IPSec},
  \texttt{WireGuard}, \texttt{OpenVPN})
\item
  Implement \texttt{TLS}/\texttt{SSL} encryption and manage \texttt{PKI}
  infrastructure
\item
  Secure \texttt{DNS} infrastructure using \texttt{DNSSEC},
  \texttt{DoH}, and \texttt{DoT}
\item
  Design and implement network segmentation and zero trust architectures
\item
  Perform network traffic analysis using \texttt{Wireshark} and
  \texttt{tcpdump}
\item
  Develop incident response procedures for network security events
\end{itemize}
