\subsection{Description}\label{description}

The \texttt{Yocto} Project has emerged as the industry standard for
creating custom embedded \texttt{Linux} distributions, powering
everything from IoT devices to automotive systems. This comprehensive
course teaches participants how to leverage \texttt{Yocto}'s powerful
build system to create maintainable, reproducible, and production-ready
embedded \texttt{Linux} systems.

Unlike traditional approaches to embedded \texttt{Linux} development,
\texttt{Yocto} provides a structured, metadata-driven framework that
scales from single-board prototypes to complex multi-platform product
lines. This course emphasizes practical, hands-on experience with modern
\texttt{Yocto} workflows, including containerized builds, \texttt{CI/CD}
integration, and security hardening.

Participants will learn not just how to use \texttt{Yocto}, but how to
architect sustainable build systems that can evolve with their products
over years of development and deployment.

\subsection{Objectives}\label{objectives}

Upon completion of this course, participants will be able to: * Design
and implement production-ready embedded \texttt{Linux} systems using the
\texttt{Yocto} Project * Create custom layers and recipes following
industry best practices * Optimize build performance and implement
efficient \texttt{CI/CD} pipelines * Implement security hardening and
license compliance workflows * Debug complex build and runtime issues
using \texttt{Yocto}'s comprehensive toolset * Deploy OTA update
mechanisms for field-deployed devices * Integrate \texttt{Yocto} builds
into modern containerized \texttt{DevOps} workflows * Make informed
decisions about when to use \texttt{Yocto} versus alternatives
