\subsection{Summary}\label{summary}

A hands on programmer in many languages. I work in at least 5-6
languages and have taught about 12. I write code from C at kernel level
for driver implementation up to enterprise Scala and most languages in
between. I'm also a good instructor and have instructed hundreds of
courses for many tech companies in Israel and around the world. I am an
architect and not only a coder and have been involved in designing the
architecture for several products: a home automation system for Intel, a
very scalable website for Yahoo, a real time application for Rafael, AWS
scalable processing app for my own private clients and more. I
instructed about 150 different courses, syllabus wise, each several
times, during the last decade usually for professionals in the industry.
From methodological courses like agile programming to very technical
courses, like multi-core programming on Intel processors to tools like
git and to philosophical courses like introducing free source to
companies. I am a self learner on most of the topics that I instruct and
use. I have a strong math background (I have not achieved M.Sc but only
due to laziness). I have managed teams on various projects but I can
also work alone. When I manage a team I try to avoid bureaucratic
practices and be part of the team. I have contributed to many free and
open source projects like the Linux kernel and I am currently the
maintainer of GNU grep(1). I code as a past time on pet projects which
you can find on github. My favourite areas are the Linux kernel, UNIX
architecture and building embedded Linux systems. I also do my own
system administration and have taught many system administration
courses. I am certified for mysql, solaris, Linux, AWS and some more
stuff. I am also a professional MySQL DBA, offered professional support
for it and have taught several MySQL courses.

I was the first associate instructor for AWS in Israel.

Lately I have been doing data science, machine learning, and NLP on
average sized data (few terabytes).
